## 一、三条定律

**第一定律（惯性定律）**：不受外力时，物体保持静止或匀速直线运动。它定义了**惯性系**。

**第二定律**：

$$\vec{F} = m\vec{a} = \frac{d\vec{p}}{dt}$$

（动量形式 $\vec{F} = \dfrac{d(m\vec{v})}{dt}$ 在变质量时更普适）

**第三定律**：$\vec{F}_{12} = -\vec{F}_{21}$（作用力与反作用力等大反向、作用在不同物体上）。

## 二、常见力

| 力 | 表达式 |
|---|---|
| 重力 | $mg$ |
| 弹力（弹簧） | $F = -kx$ |
| 摩擦力 | $f = \mu N$ |
| 万有引力 | $F = G\frac{m_1m_2}{r^2}$ |

## 三、解题步骤

1. **选研究对象**（隔离体法）
2. **受力分析**（重力、弹力、摩擦力，逐个画）
3. **建立坐标系**（沿运动方向为正）
4. **列牛顿第二定律方程**（分方向）
5. 解方程并检验

**变力情形**：若 $F$ 是位置的函数，用

$$m\frac{dv}{dt} = F(x) \Rightarrow mv\frac{dv}{dx} = F(x)$$

再积分。

## 四、惯性系与非惯性系

**惯性系**：牛顿定律成立的参考系（地面近似惯性系）。

**非惯性系**中需引入**惯性力**：

$$\vec{F}_{惯} = -m\vec{a}_0$$

例如加速车厢中引入向后的惯性力；转动参考系中引入离心力、科里奥利力。

## 五、典型例题

**例 1** 质量 $m = 2\,\text{kg}$ 的物体在水平面上，受水平拉力 $F = 10\,\text{N}$，摩擦因数 $\mu = 0.2$，$g = 10\,\text{m/s}^2$，求加速度。

> **解**：摩擦力 $f = \mu mg = 0.2\times2\times10 = 4\,\text{N}$
> $$a = \frac{F - f}{m} = \frac{10-4}{2} = 3\,\text{m/s}^2$$

**例 2** 电梯以 $a = 2\,\text{m/s}^2$ 向上加速，质量 $50\,\text{kg}$ 的人对地板的压力是多少？

> **解**：取人为研究对象，向上为正：
> $$N - mg = ma \Rightarrow N = m(g+a) = 50\times12 = 600\,\text{N}$$
> 由牛顿第三定律，人对地板的压力也是 $600\,\text{N}$（大于重力）。

## 六、易错点

- 作用力与反作用力**作用在不同物体上**，不能相互抵消
- 摩擦力方向与**相对运动（趋势）方向**相反，不一定与运动方向相反
- 非惯性系中必须补上惯性力，否则"凭空"出现加速度
