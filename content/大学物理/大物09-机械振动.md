## 一、简谐振动

**动力学方程**：

$$\frac{d^2x}{dt^2} + \omega^2x = 0$$

**运动学方程**：

$$x = A\cos(\omega t + \varphi)$$

**三要素**：振幅 $A$、角频率 $\omega$、初相 $\varphi$。

**速度与加速度**：

$$v = -A\omega\sin(\omega t+\varphi), \qquad a = -A\omega^2\cos(\omega t+\varphi) = -\omega^2x$$

## 二、常见简谐振动

**弹簧振子**：

$$\omega = \sqrt{\frac{k}{m}}, \qquad T = 2\pi\sqrt{\frac{m}{k}}$$

**单摆**（小角度）：

$$\omega = \sqrt{\frac{g}{l}}, \qquad T = 2\pi\sqrt{\frac{l}{g}}$$

**复摆**：$T = 2\pi\sqrt{\dfrac{J}{mgd}}$

## 三、简谐振动的能量

$$E_k = \frac{1}{2}mv^2 = \frac{1}{2}m\omega^2A^2\sin^2(\omega t+\varphi)$$

$$E_p = \frac{1}{2}kx^2 = \frac{1}{2}kA^2\cos^2(\omega t+\varphi)$$

**总能量守恒**：

$$E = E_k + E_p = \frac{1}{2}kA^2 = \text{常量}$$

**特点**：动能与势能**交替转换**，各以 $2\omega$ 的频率变化；平均值各为总能量的一半。

## 四、振动的合成

**同方向同频率**：

$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2-\varphi_1)}$$

- 同相（$\Delta\varphi = 0$）：$A = A_1 + A_2$（加强）
- 反相（$\Delta\varphi = \pi$）：$A = |A_1 - A_2|$（减弱）

**同方向不同频率**：产生**拍**，拍频 $\nu_{拍} = |\nu_1 - \nu_2|$。

**相互垂直同频率**：合成轨迹为**椭圆**（李萨如图形）。

## 五、阻尼振动

$$m\frac{d^2x}{dt^2} = -kx - \gamma\frac{dx}{dt}$$

- **欠阻尼**：振幅按指数衰减的振荡
- **过阻尼**：缓慢回到平衡位置，不振荡
- **临界阻尼**：最快回到平衡位置且不振荡

## 六、典型例题

**例 1** 弹簧振子 $m = 0.1\,\text{kg}$，$k = 10\,\text{N/m}$，求周期。

> **解**：
> $$T = 2\pi\sqrt{\frac{0.1}{10}} = 2\pi\times0.1 \approx 0.628\,\text{s}$$

**例 2** 单摆长 $l = 1\,\text{m}$，$g = 9.8\,\text{m/s}^2$，求周期。

> **解**：
> $$T = 2\pi\sqrt{\frac{1}{9.8}} \approx 2.0\,\text{s}$$

## 七、易错点

- 简谐振动中**加速度与位移成正比且反向**（$a = -\omega^2x$），这是判据
- 单摆周期公式只在**小角度**下成立
- 动能与势能的**变化频率是振动频率的 2 倍**
