## 一、转动惯量

$$J = \sum m_ir_i^2 = \int r^2\,dm$$

**常见刚体的 $J$**（绕质心轴）：

| 刚体 | $J$ |
|---|---|
| 细杆（绕中心垂直轴） | $\frac{1}{12}mL^2$ |
| 细杆（绕一端垂直轴） | $\frac{1}{3}mL^2$ |
| 圆盘/圆柱（绕中心轴） | $\frac{1}{2}mR^2$ |
| 圆环（绕中心轴） | $mR^2$ |
| 球（绕直径） | $\frac{2}{5}mR^2$ |

**平行轴定理**：$J = J_C + md^2$（$d$ 为两平行轴间距）

## 二、转动定律

$$\vec{M} = J\vec{\beta}$$

其中力矩 $\vec{M} = \vec{r}\times\vec{F}$，角加速度 $\beta = \dfrac{d\omega}{dt}$。

**与牛顿第二定律对偶**：$F \leftrightarrow M$，$m \leftrightarrow J$，$a \leftrightarrow \beta$。

## 三、转动动能与功

$$E_k = \frac{1}{2}J\omega^2$$

**力矩的功**：$W = \displaystyle\int_{\theta_1}^{\theta_2}M\,d\theta$

**动能定理**：$W = \dfrac{1}{2}J\omega_2^2 - \dfrac{1}{2}J\omega_1^2$

## 四、角动量与角动量守恒

**角动量**：

$$L = J\omega \quad (\text{定轴转动})$$

**角动量定理**：

$$M = \frac{dL}{dt}$$

**角动量守恒**：合外力矩为零时 $J\omega = \text{常量}$。

**应用**：花样滑冰收臂加速、离心节速器、陀螺定向。

## 五、典型例题

**例 1** 质量 $m = 2\,\text{kg}$、半径 $R = 0.5\,\text{m}$ 的匀质圆盘绕中心轴转动，求转动惯量。

> **解**：
> $$J = \frac{1}{2}mR^2 = \frac{1}{2}\times2\times0.25 = 0.25\,\text{kg·m}^2$$

**例 2** 上题圆盘受恒定力矩 $M = 1\,\text{N·m}$，求角加速度。

> **解**：
> $$\beta = \frac{M}{J} = \frac{1}{0.25} = 4\,\text{rad/s}^2$$

**例 3** 滑冰者收臂使 $J$ 减半，角速度如何变化？

> **解**：角动量守恒 $J_1\omega_1 = J_2\omega_2$，$J_2 = J_1/2$，故 $\omega_2 = 2\omega_1$，**角速度加倍**。

## 六、易错点

- 转动惯量**与转轴位置有关**，用平行轴定理时必须先取质心轴
- 角动量守恒的条件是**合外力矩为零**（合外力可以不为零，只要力的作用线过轴）
- 刚体作一般运动时 $E_k = \frac{1}{2}mv_C^2 + \frac{1}{2}J_C\omega^2$（平动 + 转动）
