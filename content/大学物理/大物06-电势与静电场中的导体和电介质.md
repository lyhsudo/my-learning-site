## 一、静电场力做功与电势能

**静电力做功与路径无关**（静电场是保守场）。

**电势能**：$W_{ab} = E_{pa} - E_{pb}$

**电势**：

$$V_a = \frac{E_{pa}}{q_0} = \int_a^{\infty}\vec{E}\cdot d\vec{l}$$

**电势差**：

$$U_{ab} = V_a - V_b = \int_a^b \vec{E}\cdot d\vec{l}$$

**点电荷的电势**：

$$V = \frac{q}{4\pi\varepsilon_0r}$$

## 二、电势叠加原理

$$V = \sum V_i = \sum\frac{q_i}{4\pi\varepsilon_0r_i}$$

（标量叠加，比场强简便）

## 三、电场强度与电势的关系

$$\vec{E} = -\nabla V = -\left(\frac{\partial V}{\partial x}\vec{i} + \frac{\partial V}{\partial y}\vec{j} + \frac{\partial V}{\partial z}\vec{k}\right)$$

**一维情形**：$E = -\dfrac{dV}{dx}$

**重要结论**：电场线**指向电势降低**的方向；等势面与电场线正交。

## 四、静电场中的导体

**静电平衡条件**：导体内部场强为零，表面场强垂直于表面。

**性质**：
1. 整个导体是**等势体**，表面是等势面
2. 电荷只分布在**表面**
3. **尖端放电**：曲率大处电荷面密度大、场强大
4. **静电屏蔽**：空腔导体可屏蔽外电场

## 五、电介质与电容

**电介质的极化**：无极分子位移极化、有极分子取向极化。

**有介质时的高斯定理**：

$$\oint \vec{D}\cdot d\vec{S} = \sum q_0 \quad (\vec{D} = \varepsilon_0\varepsilon_r\vec{E})$$

**电容**：

$$C = \frac{Q}{U}$$

| 电容器 | 电容 |
|---|---|
| 平行板 | $C = \frac{\varepsilon_0\varepsilon_rS}{d}$ |
| 球形 | $C = 4\pi\varepsilon_0\varepsilon_r\frac{R_1R_2}{R_2-R_1}$ |

**储能**：$W = \dfrac{1}{2}CU^2 = \dfrac{Q^2}{2C}$

## 六、典型例题

**例 1** 点电荷 $q = 1\times10^{-9}\,\text{C}$，求距其 $0.3\,\text{m}$ 处的电势。

> **解**：
> $$V = \frac{9\times10^9\times10^{-9}}{0.3} = 30\,\text{V}$$

**例 2** 平行板电容器 $S = 0.01\,\text{m}^2$，$d = 1\,\text{mm}$，求电容。

> **解**：
> $$C = \frac{\varepsilon_0S}{d} = \frac{8.85\times10^{-12}\times0.01}{10^{-3}} \approx 8.85\times10^{-11}\,\text{F}$$

## 七、易错点

- 电势是**标量**（可直接代数相加），场强是矢量
- 导体**内部场强为零**但**电势不一定为零**
- 有介质时用 $\vec{D}$ 的高斯定理，注意 $\vec{D}$ 与 $\vec{E}$ 的关系含 $\varepsilon_r$
