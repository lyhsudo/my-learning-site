## 一、直流电机的基本原理

**直流电动机**：通电导体在磁场中受电磁力 → 产生转矩 → 转动
**直流发电机**：导体切割磁感线 → 感应电动势 → 输出电能

**结构**：定子（主磁极、换向极、机座）+ 转子（电枢绕组、换向器、轴）

**换向器**是直流电机的关键部件，作用是**把交流变为直流**（发电机）或反之（电动机）。

## 二、基本方程式

**电枢电动势**：

$$E_a = C_e\Phi n$$

其中 $C_e$ 为电动势常数，$\Phi$ 为每极磁通，$n$ 为转速。

**电磁转矩**：

$$T = C_T\Phi I_a$$

**电枢回路电压方程**（电动机）：

$$U = E_a + I_aR_a$$

**转速公式**：

$$n = \frac{U - I_aR_a}{C_e\Phi}$$

## 三、功率与效率

**电磁功率**：

$$P_{em} = E_aI_a = T\Omega$$

**输入功率**（电动机）：$P_1 = UI_a + U_fI_f$

**效率**：

$$\eta = \frac{P_2}{P_1}$$


## 四、直流电动机的机械特性

**并励（他励）电动机**：

$$n = \frac{U}{C_e\Phi} - \frac{R_a}{C_eC_T\Phi^2}T$$

**特点**：转速随转矩增加而**略降**（硬特性），适合**恒速负载**。

**串励电动机**：

$$n \propto \frac{1}{\sqrt{T}}$$

**特点**：转矩大、转速随负载变化大（软特性），适合**启动转矩大的场合**（如电车、起重机），但**不允许空载运行**。

## 五、直流电动机的启动与调速

**启动问题**：直接启动时 $n=0$，$E_a = 0$，$I_a = U/R_a$ 极大（可达额定的 10~20 倍）。

**限制启动电流的方法**：
1. **电枢串电阻启动**（常用）
2. **降低电源电压启动**

**调速方法**：
1. **改变电枢电压** $U$（最常用，可实现无级调速）
2. **改变励磁电流**（改变 $\Phi$）
3. **电枢串电阻**（有级、损耗大）

**制动方式**：能耗制动、反接制动、回馈制动。

## 六、典型例题

**例 1** 某他励直流电动机 $U = 220\,\text{V}$，$R_a = 0.5\,\Omega$，$I_a = 20\,\text{A}$，$C_e\Phi = 0.2$，求转速。

> **解**：
> $$E_a = U - I_aR_a = 220 - 20\times0.5 = 210\,\text{V}$$
> $$n = \frac{E_a}{C_e\Phi} = \frac{210}{0.2} = 1050\,\text{r/min}$$

**例 2** 若上题直接启动（$n=0$，$E_a=0$），启动电流多大？

> **解**：
> $$I_{st} = \frac{U}{R_a} = \frac{220}{0.5} = 440\,\text{A}$$
> 达额定电流的 22 倍，必须**串电阻限流**。

## 七、易错点

- 直流电动机**不能直接启动**，必须限制启动电流
- **串励电动机绝对不允许空载运行**（空载时转速极高，会"飞车"）
- 转速公式中 $n$ 与 $\Phi$ 成反比：减弱磁场会使转速升高
- 换向器的作用是**改变电流方向**（发电机的"整流"也是同一部件）
