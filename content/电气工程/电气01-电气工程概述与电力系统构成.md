## 一、电力系统的组成

```
发电 → 升压变电 → 输电 → 降压变电 → 配电 → 用电
```

**五大环节**：
1. **发电**：把一次能源转换为电能（火电、水电、核电、风电、光伏）
2. **输电**：把电能从发电厂送到负荷中心（高压/超高压）
3. **变电**：变换电压等级
4. **配电**：把电能分配到各用户
5. **用电**：各类负荷消耗电能

**动力系统 = 电力系统 + 动力部分**（锅炉、汽轮机等）。

## 二、电压等级

**我国标准电压等级**（kV）：

$$0.38,\ 0.22,\ 3,\ 6,\ 10,\ 35,\ 110,\ 220,\ 330,\ 500,\ 750,\ 1000$$

| 范围 | 用途 |
|---|---|
| 220/380 V | 低压配电（用户） |
| 6~35 kV | 中压配电 |
| 110~220 kV | 高压输电 |
| 330~750 kV | 超高压输电 |
| 1000 kV | 特高压交流 |

> **采用高压输电的原因**：在输送功率 $P$ 一定时，电压越高，电流越小，线路损耗 $I^2R$ 越小。

## 三、电力系统的特点

1. **电能难以大量储存**：发电、输电、用电必须**实时平衡**
2. **电能不能储存 → 需要调度自动化**
3. **对可靠性要求高**：停电会造成巨大损失
4. **暂态过程极快**：电磁暂态以毫秒计，需要快速保护

**对电力系统的基本要求**：
- 保证供电**可靠性**
- 保证电能**质量**（电压、频率、波形）
- 保证运行**经济性**

## 四、电能质量指标

| 指标 | 标准 |
|---|---|
| 频率偏差 | $\pm0.2\,\text{Hz}$（大系统） |
| 电压偏差 | $\pm5\%$（35 kV 及以上） |
| 波形畸变率 | 总谐波畸变率 $\le 5\%$ |
| 三相不平衡度 | $\le 2\%$ |

> 我国额定频率为 **50 Hz**。

## 五、中性点运行方式

| 方式 | 特点 | 适用 |
|---|---|---|
| **中性点不接地** | 单相接地时线电压不变，可继续运行 2h | 35 kV 以下 |
| **中性点经消弧线圈接地** | 补偿电容电流，减小电弧 | 35~66 kV |
| **中性点直接接地** | 单相接地电流大，保护易动作 | 110 kV 及以上 |

## 六、典型例题

**例 1** 为什么远距离输电采用高电压？

> **解**：输送功率 $P = \sqrt{3}U_I I\cos\varphi$ 一定时，$U$ 越高则 $I$ 越小，
> 线路损耗 $\Delta P = 3I^2R$ 与 $I^2$ 成正比，故**升高电压可大幅降低线损**。

**例 2** 某系统频率偏差达到 0.5 Hz，是否合格？

> **解**：大系统允许偏差为 $\pm0.2\,\text{Hz}$，$0.5 > 0.2$，**不合格**。

## 七、易错点

- **电能不易大量储存**是电力系统的根本特点，一切运行策略都源于此
- 中性点接地方式不同，**单相接地故障的处理方式不同**，不能混用
- 电压等级越高，绝缘要求越高，不是"越高越好"
