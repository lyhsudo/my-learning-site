## 一、变压器的基本结构

**铁心** + **绕组**（原边 $N_1$、副边 $N_2$）。

**分类**：电力变压器、仪用互感器、自耦变压器、电焊变压器。

## 二、理想变压器的基本关系

**电压比**：

$$\frac{U_1}{U_2} = \frac{N_1}{N_2} = k$$

**电流比**：

$$\frac{I_1}{I_2} = \frac{N_2}{N_1} = \frac{1}{k}$$

**阻抗变换**：

$$Z_1 = k^2Z_2$$

> **注意**：以上是理想变压器（无损耗、无漏磁、$\mu\to\infty$）的关系。

## 三、变压器的额定值

| 参数 | 含义 |
|---|---|
| $S_N$ | 额定容量（VA 或 kVA），**按副边额定电压与电流计算** |
| $U_{1N}$ | 原边额定电压 |
| $U_{2N}$ | 副边额定电压（**空载**时） |
| $I_{1N}, I_{2N}$ | 原副边额定电流 |

$$S_N = U_{1N}I_{1N} = U_{2N}I_{2N}$$

> **注意**：变压器容量用**视在功率**表示，因为其损耗与功率因数关系复杂。

## 四、变压器的运行分析

**空载运行**：
- 原边加额定电压，副边开路
- 空载电流 $I_0$ 很小（约为额定的 $2\%\sim10\%$），主要作用是**励磁**
- 空载损耗 $P_0 \approx$ **铁耗**

**负载运行**：
- 磁动势平衡：$\dot{I}_1N_1 + \dot{I}_2N_2 = \dot{I}_0N_1$
- 负载增大时，$I_2$ 增大，$I_1$ 随之增大

**短路试验**：
- 副边短路，原边加**降低的电压**使电流达额定
- 短路电压 $U_k$ 约为额定的 $4\%\sim10\%$
- 短路损耗 $P_k \approx$ **铜耗**

## 五、损耗与效率

**总损耗**：

$$\sum P = P_{Fe} + P_{Cu}$$

- 铁耗 $P_{Fe}$：与**电压**有关，与负载无关（近似恒定）
- 铜耗 $P_{Cu}$：与**负载电流的平方**成正比

**效率**：

$$\eta = \frac{P_2}{P_1} = 1 - \frac{\sum P}{P_2 + \sum P}$$

**最大效率条件**：当**铜耗 = 铁耗时**效率最高：

$$\beta^2P_k = P_0 \Rightarrow \beta = \sqrt{\frac{P_0}{P_k}}$$

（$\beta$ 为负载系数）

## 六、三相变压器的连接组别

**连接方式**：Y（星形）、Δ（三角形）

**常见组别**：
- **Y,yn0**：配电变压器常用
- **Y,d11**：电力系统常用
- **YN,d11**：高压侧中性点引出

**组别号**：表示副边线电压滞后原边线电压的角度除以 30°。

## 七、典型例题

**例 1** 变压器 $S_N = 100\,\text{kVA}$，$U_{1N}/U_{2N} = 10/0.4\,\text{kV}$，求原副边额定电流。

> **解**：
> $$I_{1N} = \frac{S_N}{U_{1N}} = \frac{100\times10^3}{10\times10^3} = 10\,\text{A}$$
> $$I_{2N} = \frac{S_N}{U_{2N}} = \frac{100\times10^3}{400} = 250\,\text{A}$$

**例 2** 某变压器 $P_0 = 500\,\text{W}$，$P_k = 2000\,\text{W}$，求最大效率时的负载系数。

> **解**：
> $$\beta = \sqrt{\frac{P_0}{P_k}} = \sqrt{\frac{500}{2000}} = 0.5$$
> 即负载为额定的一半时效率最高。

## 八、易错点

- 变压器容量用**视在功率**（VA），不是有功功率（W）
- **空载损耗近似等于铁耗**，**短路损耗近似等于铜耗**——这是两个重要的对应关系
- 最大效率出现在**铜耗 = 铁耗**时，通常不是额定负载，而是 $\beta < 1$
- 变比 $k$ 是**匝数比**，也等于**空载电压比**
