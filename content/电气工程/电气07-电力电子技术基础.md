## 一、电力电子器件的分类

按**控制能力**分：

| 类型 | 特点 | 典型器件 |
|---|---|---|
| **不控型** | 不能控制通断 | 电力二极管 |
| **半控型** | 只能控制开通 | 晶闸管（SCR） |
| **全控型** | 可控制开通与关断 | GTO、GTR、**IGBT**、MOSFET |

> **IGBT** 是目前应用最广的全控型器件，兼具 MOSFET 的驱动简单与 GTR 的低导通压降。

## 二、电力电子电路的四大基本类型

| 类型 | 功能 | 能量流向 |
|---|---|---|
| **整流（AC-DC）** | 交流变直流 | AC → DC |
| **逆变（DC-AC）** | 直流变交流 | DC → AC |
| **直流斩波（DC-DC）** | 直流电压变换 | DC → DC |
| **交流调压（AC-AC）** | 交流电压变换 | AC → AC |

## 三、可控整流电路

**单相半波可控整流**（电阻负载）：

$$U_d = \frac{U_2}{\pi}\cdot\frac{1+\cos\alpha}{2}\times\pi \quad(\text{简化记法})$$

更准确的表达式：

$$U_d = 0.45U_2\frac{1+\cos\alpha}{2}$$

**单相全控桥式整流**（电阻负载）：

$$U_d = 0.9U_2\frac{1+\cos\alpha}{2}$$

其中 $\alpha$ 为**控制角（触发延迟角）**。

**移相范围**：电阻负载时 $\alpha \in [0°, 180°]$。

> **结论**：改变 $\alpha$ 即可调节输出直流电压——这是可控整流的本质。

## 四、逆变电路

**分类**：
- **有源逆变**：把直流电逆变为与电网同频同相的交流，回馈电网
- **无源逆变**：逆变为任意频率的交流供给负载（如变频器）

**逆变产生的条件**：
1. 要有**直流电源**
2. 要有**全控器件**（或能关断的半控器件）
3. 负载要有**感性或电势**

**电压型逆变器 vs 电流型逆变器**：
- 电压型：直流侧并大电容，输出**电压**为方波
- 电流型：直流侧串大电感，输出**电流**为方波

## 五、PWM 控制技术

**PWM（脉宽调制）**：通过改变脉冲宽度来调节输出电压大小。

**SPWM（正弦脉宽调制）**：使脉冲宽度按正弦规律变化，输出接近正弦波。

**调制比**：

$$M = \frac{U_r}{U_c}$$

（$U_r$ 调制波幅值，$U_c$ 载波幅值）

**优点**：
- 输出谐波少
- 可同时实现**调压与调频**
- 效率高

## 六、典型应用

| 应用 | 电路 |
|---|---|
| **直流调速** | 可控整流 + 直流电动机 |
| **交流调速（变频器）** | 整流 + 逆变 + 异步电动机 |
| **不间断电源（UPS）** | 整流 + 蓄电池 + 逆变 |
| **高压直流输电（HVDC）** | 整流 + 直流线路 + 逆变 |
| **开关电源** | 整流 + 高频斩波 + 变压 |

## 七、典型例题

**例 1** 单相全控桥式整流，$U_2 = 100\,\text{V}$，$\alpha = 60°$，求输出直流电压。

> **解**：
> $$U_d = 0.9\times100\times\frac{1+\cos60°}{2} = 90\times\frac{1.5}{2} = 67.5\,\text{V}$$

**例 2** 若 $\alpha = 0$，输出多少？

> **解**：
> $$U_d = 0.9\times100\times\frac{1+1}{2} = 90\,\text{V}$$
> 这就是不可控整流的输出电压（$0.9U_2$）。

## 八、易错点

- **晶闸管是半控型器件**，只能控制开通，不能控制关断（关断需电流过零或强迫换流）
- 可控整流输出公式中 $\alpha$ 是**控制角（延迟角）**，$0°$ 对应全导通
- 逆变电路不一定需要全控器件——**有源逆变用晶闸管即可**
- PWM 既能调压又能调频，这是变频器的基础
