# 我的课程知识库

一个**纯离线的工科课程复习站** —— 8 个学科、103 篇笔记、7 万字、2459 个公式容器。
没有构建步骤、没有依赖、没有后端：**双击 `index.html` 就能用**。

为「一个人备考自己的专业课」而写，不是通用的笔记软件。

## 快速开始

```bash
# 方式一：直接打开（推荐）
双击 index.html

# 方式二：本地服务（Service Worker 离线缓存需要 http(s) 才生效）
python -m http.server 8899 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8899/
```

## 功能

| 模块 | 说明 |
|---|---|
| **笔记阅读** | Markdown + KaTeX 公式（按需加载，不压首屏）、目录、双向链接 `[[标题]]`、反向链接 |
| **闪卡** | Leitner 间隔重复，支持从笔记一键生成、AI 生成 |
| **错题集** | 练习判错自动收录，可让 AI 生成解析 |
| **知识链** | 把相关笔记按「由易到难」串成一条链，学完一环解锁下一环 |
| **知识图谱** | 笔记之间的链接关系可视化 |
| **学习分析** | 掌握度分布、学习热力图、连续打卡、难点排序（自动算难度系数） |
| **工作台** | 今日目标、待办、最近动态 |
| **AI 辅导** | 苏格拉底式追问 / 出题 / 总结 / 解释难点。自带 API Key，支持任意 OpenAI 兼容接口 |
| **备份** | 一键导出 / 导入全部本地数据（JSON） |

## 技术特点

- **零依赖**：没有框架、没有打包器、没有 CDN。`file://` 直接可跑
- **数据全在本地**：所有学习数据存 `localStorage`，不上传任何服务器。AI 功能直连你自己配置的接口
- **离线可用**：Service Worker 缓存应用外壳 + KaTeX，断网后仍能完整打开并渲染公式
- **可访问性**：图标按钮带可访问名、标题层级连续、打印样式单独调过（文章页打印零交互残留）
- **5 套配色 × 明暗 = 10 组主题**：默认「液态玻璃」，另有终端琥珀 / 暖纸书桌 / 墨灰 / 深蓝

## 目录结构

```
.
├── index.html            入口（含启动前置脚本：首帧即应用主题，避免白闪）
├── data.js               构建产物：全部文章与分类数据（由 content/ 生成）
├── assets/
│   ├── app.js            应用逻辑（单文件，含路由 / 渲染 / 状态机）
│   ├── style.css         设计系统实现（变量化的刻度：字号 / 间距 / 圆角 / 动效）
│   ├── icon.svg          PWA 图标
│   └── katex/            KaTeX 本地副本（按需加载）
├── content/              内容源：8 个学科目录，每个 .md 带 frontmatter
├── build.py             构建脚本：content/**/*.md → data.js
├── sw.js                Service Worker
├── manifest.json        PWA manifest
└── .impeccable.md       设计宪法（改视觉前必读）
```

## 内容构建

笔记写在 `content/<学科>/<文件>.md`，顶部 frontmatter：

```markdown
---
title: 高等数学 · 函数与极限
category: 高等数学
tags: [极限, 无穷小]
date: 2026-09-10
---

正文……
```

改完内容后重新生成 `data.js`：

```bash
python build.py
```

字数的口径是 `汉字数 + 英文/数字词组数`（见 `build.py` 的 `word_count()`）。

## 设计系统

所有视觉决策在 [`.impeccable.md`](.impeccable.md) —— 那是一部「设计宪法」，不是随手写的说明：

- 颜色即状态，不是装饰（颜色必须承载语义）
- 层级靠刻度、线与高度，阴影只表达「离底多远」
- 悬停「浮起」只能用阴影升级表达，**元素本身一动不动**
- 主题换色不换秩序：10 组配色只改颜色，不改层级、间距、圆角、动效时长
- 改任何视觉前先读它；改完要同步更新它
